CSharp Syntax Basics
====================
C# syntax basics, including examples and explanations of various language features. 
It serves as a reference for developers who are new to C# or want to refresh their knowledge of the language.
Some of the topics covered include:
- C# is case-sensitive, meaning that variable names, method names, and other identifiers must be written with the correct capitalization.
- C# uses semicolons (;) to terminate statements, and curly braces ({}) to define blocks of code.
